03

Job Alert Automation

Gebouwd om mijn eigen sollicitatieproces te automatiseren. Een scanner haalt via de Adzuna API dagelijks vacatures op en laat Claude API ze scoren tegen mijn eigen criteria. GitHub Actions draait dit elke ochtend, en de beste matches landen vanzelf in mijn mailbox. Ik schreef de architectuur en een gedetailleerde technische spec, inclusief edge cases zoals API-limieten en dubbele meldingen; Claude Code implementeerde de Python.

Draait volledig zelfstandig, elke ochtend opnieuw: geen handmatig zoeken meer nodig. De zoekradius bestrijkt 60km rond Purmerend, plus remote en hybride functies. Elke vacature krijgt een score en een korte motivatie, zodat duidelijk is waarom iets wel of niet doorkwam. Zelf geen match? Dan blijft de mailbox leeg, in plaats van ruis te sturen.
